# The Recursive Organization System

**Definition:** A universal architecture that organizes everything. It reveals what your mindset actually is—not what you think it is.

**Structure:**
- **12 Vertical Levels:** Roots → Meaning → Behavior → Identity → Attention → Values → Decisions → Rhythms → Energy → Systems → Action → Purpose.
- **5 Horizontal Pillars:** Orientation, Training, Nourishment, Regulation, Recovery.

**Diagnostic Principle:** "When results break down, don't fix the symptom—go upstream to the highest level that is organizing the breakdown."

**Function:** Diagnoses breakdowns by going upstream to the highest organizing level. Replaces symptom-fixing and linear improvement models.

**Application:** Coaching, self-assessment, organizational design, habit architecture.

**Downstream Use:** Core architecture for Isaac (Book), Stephen (Articles), Walt (Offers).
