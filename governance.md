# Repository Governance

## Version Control
- This repository is versioned. All changes are tracked in `CHANGELOG.md`.
- Major updates to frameworks or the category claim require a version increment.

## Update Rules
- Only the author (Ethan Alan Keen) or authorized agents may commit changes.
- All framework updates must maintain backward compatibility with the core category claim.
- New case studies or proof points are added to the `/proof` directory and linked in `canonical_index.md`.

## Canonical Integrity
- Do not rename core files or directories without updating the index.
- Do not consolidate separate frameworks into a single file.
- All public-facing content must align with the `canonical_citation.md` terms.
